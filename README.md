# 📖 المرجع الشامل — الامتحان الجهوي الموحد (الاجتماعيات 3AC)

موقع وتطبيق ويب تقدمي (PWA) للمراجعة العامة الشاملة استعدادا للامتحان الجهوي الموحد لنيل شهادة السلك الإعدادي — مادة الاجتماعيات، وفق الإطار المرجعي الرسمي (دورة يوليوز 2022).

**✍️ إعداد: ذ. أحمد بوعمود — مؤسسة الحنان الخاصة، أكادير | 2025-2026**

---

## ✨ المحتوى

| القسم | التفاصيل |
|---|---|
| 🎯 الإطار المرجعي | شرح المكونات الثلاثة للامتحان (تعاريف 6ن / وثائق 7ن / مقالي 7ن) وقاعدة تناوب المواد |
| 📕 التاريخ | 5 دروس مفصلة: النازية، ح.ع.2، القضية الفلسطينية، كفاح الاستقلال، الدولة المغربية الحديثة |
| 📗 الجغرافيا | 6 دروس: و.م.أ، اليابان، روسيا، مصر، نيجيريا، النهج الجغرافي |
| 📘 التربية على المواطنة | 5 دروس: التراث، البيئة، الموارد الطبيعية، حوار الأديان، البرامج الإعلامية |
| 🧭 المنهجيات | 6 أدوات: النص التاريخي، الموضوع المقالي، الوصف والتفسير، الأعمدة/المنحنى، الدائرة، الخط الزمني |
| 💡 نصائح الامتحان | 7 محاور: الاستعداد، تدبير الوقت، قاموس أفعال الامتحان، حيل الحفظ... |

## 🚀 المميزات

- ✅ يعمل **بدون إنترنت 100%** بعد أول زيارة (Service Worker)
- 📲 **قابل للتثبيت** كتطبيق على الهاتف والحاسوب (PWA)
- 🔎 **بحث فوري** في كل الدروس والمفاهيم مع تظليل النتائج
- 🌙 **وضع ليلي** مريح للعين + تحكم في حجم الخط + وضع العرض للمسلاط
- ✓ تتبع تقدم المراجعة (علامة "تمت مراجعته" لكل درس)
- 🖨️ صفحات قابلة للطباعة

## 🗂️ بنية المشروع

```
├── index.html        # الصفحة الرئيسية (التطبيق كاملا)
├── css/style.css     # التصميم
├── js/app.js         # المنطق والميزات
├── manifest.json     # إعدادات PWA
├── sw.js             # Service Worker (العمل بدون إنترنت)
├── icons/            # أيقونات التطبيق
├── apk/              # نسخة APK لأندرويد (تُضاف عبر PWABuilder)
└── docs/BUILD-APK.md # دليل توليد APK
```

## 🌐 النشر

الموقع جاهز للنشر مباشرة على **Netlify** (اسحب المجلد إلى Netlify Drop) أو عبر الربط بهذا المستودع للنشر التلقائي.

## 📱 توليد نسخة APK

راجع الدليل الكامل في [`docs/BUILD-APK.md`](docs/BUILD-APK.md) — باختصار: انشر الموقع، ثم استعمل [PWABuilder.com](https://www.pwabuilder.com) لتوليد APK موقّع خلال دقائق، وضعه في مجلد `apk/`.
