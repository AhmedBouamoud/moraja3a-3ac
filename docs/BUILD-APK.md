# 📱 دليل توليد نسخة APK من الموقع

التطبيق مبني كـ PWA كامل (manifest + service worker + أيقونات)، لذا يمكن تحويله إلى APK حقيقي **خلال 5 دقائق وبدون كتابة أي سطر برمجي** عبر أداة PWABuilder الرسمية من مايكروسوفت:

## الخطوات

1. **انشر الموقع أولا** على Netlify:
   - ادخل إلى https://app.netlify.com/drop
   - اسحب مجلد المشروع كاملا → ستحصل على رابط مثل `https://almarjaa-aljihawi.netlify.app`

2. **افتح PWABuilder**: https://www.pwabuilder.com
   - ألصق رابط موقعك واضغط **Start**
   - ستظهر نتيجة فحص PWA (يجب أن تكون كل العلامات خضراء ✅)

3. **اختر Android** ثم **Generate Package**:
   - Package ID مقترح: `com.bouamoud.almarjaa`
   - App name: `المرجع الشامل`
   - اضغط Download → ستحصل على ملف `.apk` (نسخة موقعة للتجريب) و`.aab` (للنشر في Google Play)

4. **ضع ملف APK في الموقع**:
   - أعد تسميته إلى `almarjaa-aljihawi.apk`
   - ضعه داخل مجلد `apk/` في المستودع وادفع التغيير
   - زر "⬇️ تحميل نسخة APK" في الموقع سيعمل تلقائيا

## ملاحظات

- بدون APK أيضا، زر "📲 تثبيت التطبيق" في الموقع يثبته مباشرة على أندرويد وiOS والحاسوب (تجربة مطابقة للتطبيق).
- لتحديث التطبيق بعد تعديل المحتوى: غيّر رقم النسخة في `sw.js` (السطر الأول: `almarjaa-v1.0` → `v1.1`).
